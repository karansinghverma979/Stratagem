# Contributing to Stratagem ♟️

Thank you for your interest in contributing to **Stratagem**! Stratagem is designed as an autonomous, high-velocity execution framework for milestone governance, strategic planning, and tactical execution.

---

## 🛠️ Development Workflow

1. **Fork or Branch**:
   - Create a feature branch from `main`:
     ```bash
     git checkout -b feat/your-feature-name
     ```

2. **Code Standards**:
   - Follow clean architecture principles.
   - Maintain modularity, deterministic state transitions, and zero unnecessary dependencies.
   - Format with Prettier before submitting.

3. **Commit Messages**:
   - Use conventional commit formats:
     - `feat:` for new capabilities
     - `fix:` for bug fixes
     - `docs:` for documentation updates
     - `refactor:` for code refactoring without behavior change

---

## 🚀 Pull Request Checklist

Before submitting your PR, ensure:
- [ ] The PR title follows conventional commit formatting.
- [ ] Code compiles and passes all linting/testing suites.
- [ ] Documentation and README are updated in lockstep with code changes.
- [ ] Any breaking changes are clearly highlighted in the description.
