## 🎨 1. The Vision: Peak Cinematic Frontend Artistry

**Stratagem** was born out of a profound dissatisfaction with existing productivity software. Tools like Trello, Jira, and Todoist treat human ambition like accounting spreadsheets—flat, sterile, and uninspiring.

We set out to answer a radical question:
> *"What if your daily task manager looked and felt like the tactical bridge of an interplanetary battlecruiser?"*

Over three major release iterations (**v1.0.1**, **v2.0.0**, and **v3.0.0**), Stratagem became a technical showcase of advanced frontend craftsmanship:
* **Volumetric Glassmorphism**: Deep backdrop filters, custom SVG matrix scanlines, dynamic color-split glitch shaders, and layered z-index depth.
* **Audio Synthesis**: Interactive Web Audio API frequency oscillators providing distinct mechanical clicks, target-lock alarms, and victory fanfares.
* **Complex Data State Machines**: Drag-and-drop HTML5 Kanban lanes, dynamic circular SVG countdown rings, and custom temporal calendar mathematics.

Stratagem stands as living proof that desktop utilities do not have to look utilitarian—they can be breathtaking works of interactive art.

## ⚡ 3. The Resource Reality & Engineering Trade-Off

As Stratagem evolved to its flagship **v3.0.0** release, we implemented exhaustive optimizations:
* Svelte `{#if}` conditional unmounting reduced idle memory by 60%.
* Asynchronous file I/O moved heavy disk reads off the main thread.
* The **Cyber-Stasis Protocol (`Ctrl + Alt + S`)** enabled operators to manually drop CPU and GPU loads to zero when minimized.

However, an immutable law of software engineering remained:
> **Extreme visual opulence carries a persistent hardware cost.**

Rendering dozens of simultaneous CSS backdrop blurs, continuous SVG animations, complex shadow hierarchies, and an Electron browser process inevitably demands significant workstation RAM (300 MB–800 MB) and GPU resources. For power users running heavy local LLMs, compiling large C++/Rust codebases, or working on battery-constrained laptops, running a visually lavish command center in the background created measurable resource contention.

## 🚀 4. The Genesis of Campaigns: The Lean Daily Driver

Recognizing this trade-off, lead architect **Karan Singh Verma** made a strategic decision:
1. **Preserve Stratagem as a Permanent Milestone**: Freeze Stratagem at its peak v3.0.0 state as an authoritative, standalone desktop showcase.
2. **Engineer a New Lightweight Sovereign**: Build **[Campaigns](https://github.com/karansinghverma979/Campaigns)**—a reimagined tactical engine designed from the ground up for raw speed, zero latency, and absolute resource minimalism.

### What Changed in Campaigns?
* **Minimalist Performance**: Stripped away heavy GPU shaders, particle overlays, and audio oscillators, allowing the app to idle with negligible RAM and zero CPU impact.
* **Deep Obsidian Integration**: Direct, real-time bidirectional synchronization with local Obsidian Markdown vaults and SQLite state-machines.
* **Multi-Minister Governance**: Introduced the Pancha-Tattva ministerial framework (`Adhipati`, `Bhakta`, `Antaryami`, `Jigyasu`) for balanced personal life operations.
