## 🔴 Flagship Innovations in Stratagem 3.0

### 1. 🔴 The Cyber-Stasis Protocol (Deep System Hybernation)
* **Instant Resource Evacuation**: Press **`Ctrl + Alt + S`** or minimize the window (**`Win + M`**) to immediately drop active CPU usage to **0.0% – 0.1%** and GPU VRAM rendering load to **0%**.
* **Zero Work Loss**: Active drafts, unfinished subtasks, and modal positions are frozen in memory without state loss.
* **Electron `powerMonitor` Auto-Stasis**: Automatically detects when the operating system goes idle or locks the screen, placing Stratagem into full stasis.
* **Configurable Sleep Timers**: Configurable in Genesis Settings (`1 Min`, `3 Mins`, `5 Mins`, `10 Mins`, `15 Mins`).

* Uses native Electron OS power queries to detect when the workstation is running on battery power.

### 3. ⌨️ Tactical Keyboard Navigation Protocol
* Complete hands-free keyboard velocity:
  * **`J`** / **`K`**: Linear task row selection down and up.
  * **`Enter`**: Expands the complete Mission Protocol view.
  * **`Space`**: Checks/unchecks subtask objectives.
  * **`Ctrl + K`**: Opens universal fuzzy-search command palette.
  * **`Esc`**: Dismisses overlays and returns focus to the main HUD.
