# Security Policy

## Supported Versions

| Version | Supported          |
| :------ | :----------------- |
| 3.x     | :white_check_mark: |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

The maintainers take the security of **Stratagem** seriously. If you discover a security vulnerability, we appreciate your efforts to coordinate with us responsibly.

### Disclosure Protocol

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Please disclose responsibly via **[GitHub Private Security Advisories](https://github.com/karansinghverma979/Stratagem/security/advisories/new)** or contact the lead maintainer directly at `karansinghverma979@gmail.com`.
3. Please include:
   - Type of issue (e.g., local IPC privilege escalation, buffer overflow, arbitrary code execution)
   - Step-by-step instructions or proof-of-concept to reproduce the vulnerability
   - Affected version(s) and operating system environment

### SLA & Remediation Timeline

* **Acknowledgment**: Within 48 hours of initial report receipt.
* **Assessment**: Severity triaged according to CVSS standard within 5 business days.
* **Resolution**: Security patches will be issued via release tag and published release note.
