# Frequently Asked Questions (FAQ)

### What is Stratagem?
Stratagem is an executive strategic planning and milestone execution engine designed to manage campaigns, strikes, and tactical operational workflows.

### Is Stratagem open source?
Yes, Stratagem is open source under the MIT license. Contributions, suggestions, and pull requests are welcomed.

### How do I report issues?
You can open an issue via the GitHub Issues tab or start a Q&A thread in GitHub Discussions.
