# Stratagem Tactical Lexicon & Glossary

- **Campaign**: A high-level strategic initiative comprising multi-phase milestones.
- **Strike**: A single, non-divisible daily tactical action mapped to a specific operational domain.
- **Subtask**: An atomic component within a campaign milestone work-tree.
- **Minister**: Autonomous domain governor (Adhipati, Bhakta, Antaryami, Jigyasu).
