# Security Policy

## Reporting Security Issues

We take the security of Stratagem seriously. If you discover a security vulnerability, please do NOT create a public issue.

Instead, please send an advisory or disclose responsibly via GitHub Security Advisories or contact the maintainers directly.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |
